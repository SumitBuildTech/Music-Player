# 🎵 Music Player

A simple and responsive music player built using HTML, CSS, and JavaScript.

## ✨ Features

- ▶️ Play and Pause songs
- ⏭️ Next and Previous song
- 🎵 Playlist
- 📊 Song progress bar
- ⏱️ Song duration
- 🔄 Autoplay option
- 📱 Simple and responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
